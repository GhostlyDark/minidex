# Minidex
This lightweight and minimalist webapp compiles all the locations of all Pokémon across every game in the series. Find Pokémon information quickly and keep track of your Pokédex progress. No registration/installation required!

**Features:**
* all regional+national Pokédex from RBY up to Sword and Shield+DLC
* quick Pokémon search (name or number) at anytime
* search by location or Pokémon type
* click on a location title to get a list of all Pokémon in that location
* users can keep track of their regional Pokédex progress by marking caught Pokémon
* made in Vanilla JS, very lightweight
* design focused on speed and usability
* responsive design for best user experience for both desktop and mobile (swipe can be used to navigate through Pokémon)
* can be installed as a progressive webapp and run completely offline

It's aimed primarily at completionists, but there is also some basic competitive information. Shortcut links to other famous sites are shown in case a user needs them.



### Translations ###
